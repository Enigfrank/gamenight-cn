# 🎮 GameNight - CN

> 自托管的多人派对游戏。默认局域网即开即玩，无需注册账号；也可部署到公网与远方的朋友联机。

**GameNight** 将任意设备转变为派对游戏主机。

单条命令启动 → 分享房间号或链接 → 立即开玩。无数据库，房间状态全部保存在内存中。

## ✨ 功能特性

* 🌐 **开箱即玩** — 无需数据库、无需注册，启动服务后浏览器打开即玩
* 📱 **多端兼容** — 手机、平板、笔记本电脑及任意现代浏览器均可运行
* 🏠 **房间代码** — 创建房间后，分享 6 位字母房间号即可加入
* 🔗 **智能邀请链接** — 大厅一键复制链接，打开即自动预填房间号
* 🎭 **100 种头像** — 根据昵称自动分配头像颜色，支持弹窗浏览并更换
* 💾 **本地偏好记忆** — 自动保存并在下次访问时恢复昵称与头像
* ⚙️ **规则可配置** — 房主可在开局前调整棋盘、时长、轮数与赛制
* 📖 **内置游戏规则** — 首页与大厅均可打开"游戏规则"弹窗查阅
* � **观战与旁观** — 非对局玩家自动观战；社交局中出局玩家可继续旁观
* 🌙 **深色模式** — 手动切换明暗主题，选择游戏页面右上角一键切换
* 🔒 **内置安全加固** — CSP 安全头、频率限制、身份令牌与输入白名单校验，可直接部署公网

> **说明：** 游戏进行中若网络瞬断，客户端会自动重连；但刷新或关闭页面会作为掉线处理并退出当前对局（房间状态仅保存在内存中）。

## 🚀 快速上手

### 环境要求

* [Node.js 18+](https://nodejs.org/en/download)

### 安装依赖

```bash
git clone https://github.com/Enigfrank/gamenight-cn.git
cd gamenight-cn
npm install
```

### 启动服务

| 平台 | 命令 |
| --- | --- |
| Windows | 双击 `start.bat` 或在终端中执行该文件 |
| macOS / Linux | `./start.sh` |
| 跨平台通用 | `npm start` |
| 开发模式（文件改动自动重启） | `npm run dev` |

在浏览器中打开 **[http://localhost:4000](http://localhost:4000)**（可用 `PORT` 环境变量更改端口）。

## 🌐 局域网联机

服务端启动后输出访问地址：

```
🎮  GameNight 启动成功！

  本地访问:    http://localhost:4000
  局域网访问:  http://gamenight.local:4000  ← 把这个地址发给朋友们！

  同一 WiFi / 局域网内的设备用任意浏览器打开即可。
```

处于**同一 Wi-Fi 或局域网**下的设备直接访问该地址即可加入，客户端无需配置环境。

服务端默认通过 **mDNS (Bonjour)** 广播，在多数设备上可直接通过固定主机名访问：

```
http://gamenight.local:4000
```

> **提示：** macOS、iOS、Android 及多数 Linux 桌面系统原生支持 `gamenight.local`。Windows 系统可能需要安装 [Bonjour for Windows](https://support.apple.com/kb/DL999)。若域名无法解析，可查询本机局域网 IP 后用 `http://<本机IP>:4000` 访问。

## ☁️ 公网部署

应用本身已包含面向公网的安全加固（安全响应头、CORS 白名单、单 IP 频率限制、游戏身份令牌、消息体积限制与输入白名单）。推荐使用 nginx / Caddy 等反向代理终止 HTTPS 后转发到本服务。

### 环境变量

| 变量 | 示例 | 说明 |
| --- | --- | --- |
| `PORT` | `4000` | 监听端口，默认 4000 |
| `TRUST_PROXY` | `1` | **仅在反向代理后设置**，限流才能取得真实客户端 IP；直连公网时切勿开启（否则可伪造请求头绕过限流） |
| `ALLOWED_ORIGINS` | `https://game.example.com` | 允许跨域访问的来源白名单，多个用逗号分隔；不设置则仅允许同源 |
| `DISABLE_MDNS` | `1` | 公网部署建议设置，关闭局域网 mDNS 广播 |
| `ADMIN_PASSWORD` | `自定义强密码` | 管理后台（`/admin`）登录密码：查看全部在线房间并观战对局；不设置则后台禁用 |

PowerShell 示例：

```powershell
$env:TRUST_PROXY='1'
$env:ALLOWED_ORIGINS='https://game.example.com'
$env:DISABLE_MDNS='1'
node server.js
```

反向代理需开启 WebSocket 升级（`Upgrade` / `Connection` 头）以支持 Socket.IO；HSTS 等传输层安全头建议在反向代理层配置。

## 📖 游戏规则

规则已集成至应用内部 —— 点击首页或大厅中的 **"游戏规则"** 即可查阅。以下为核心机制概述：

### 🔪 谁是杀手

玩家将被秘密分配为**杀手**、**医生**或**村民**。身份默认隐藏，点击角色卡即可查看，也可使用"隐藏身份"按钮防窥屏。

黑夜降临时，杀手秘密选择一名受害者，医生秘密守护一名玩家（可以是自己）；若医生守对目标则无人死亡。约每 5 名玩家配置 1 名医生。白天所有存活玩家自由讨论，随后全员投票淘汰一名嫌疑人，平票则无人出局，被淘汰者身份向全员公开。村民投票淘汰杀手即获胜；杀手将存活人数削减至 2 人即获胜。已出局玩家仅可旁观。

### ⭕ 井字棋

经典 3×3 棋盘。系统随机分配 X / O，**X 固定先手**，轮流点击空格落子，先在横、纵或对角线连成 3 子者赢得本局；9 格填满无胜者为平局。每局结束后双方符号互换。可选择自由对战累计比分，或 3 局 2 胜 / 5 局 3 胜 / 7 局 4 胜赛制。3 人以上房间可开启单败淘汰赛。

### 🔵 五子棋

**黑棋先手**，双方轮流在棋盘交叉点落子，落子无悔。在横、竖或任意斜线方向率先连成五颗同色棋子即获胜，采用无禁手规则；棋盘填满无人五连则平局。人人对战每局结束交换先后手；人机模式下玩家执黑，AI 提供简单 / 普通 / 困难三档难度，困难 AI 会封堵活三、活四并预判反击。

### 🎨 Scribble

每轮一名玩家担任画师，从备选秘密词中选一个在共享画布上作画（画笔 / 橡皮擦 / 填充 / 清空工具），其余玩家只能看到词长提示并在聊天框竞猜。猜得越快得分越高，30 秒与 55 秒时会给出线索提示；每有一人猜中画师也获得积分。猜对后不能再发聊天消息以防剧透。所有轮次结束后总分最高者获胜。

### 🃏 UNO

标准 UNO 规则，每人初始 7 张手牌。打出与弃牌堆顶颜色或数字匹配的牌，无牌可出则摸一张。特殊牌包括**跳过**、**反转**（两人对局时等同跳过）、**+2**、可指定颜色的**万能牌**以及**万能 +4**。仅剩一张牌时系统自动喊 UNO，最先出完手牌者获胜。

## 🛠️ 技术栈

| 层次 | 技术组件 |
| --- | --- |
| 运行时 | Node.js 18+ |
| HTTP 服务端 | Express 5 |
| 实时通信 | Socket.IO 4（WebSockets） |
| 局域网发现 | bonjour-service（mDNS / Bonjour） |
| 画布绘制 | HTML5 Canvas API |
| 前端实现 | 原生 JavaScript、纯 CSS（无前端框架） |
| 样式系统 | CSS 自定义属性（Variables），内置明暗双主题 |
| 数据存储 | 无数据库，房间状态纯内存 |
